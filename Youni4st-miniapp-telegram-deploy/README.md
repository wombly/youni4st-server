# Youni4st Mini App 1.2.0

Telegram Mini App на Flutter. Интерфейс и каталог перенесены на основу Android 0.8.2. Это веб-адаптация, не APK и не бинарная конвертация Kotlin.

## Что обновлено

- Главная: компактный логотип слева, синий AI-баннер, три кнопки без горизонтального скролла, четыре раздела без цифр и звёздочек, нижняя панель навигации.
- Вход только через Telegram. Имя, аватар и username из проверенных сервером данных Telegram. Обязательный статус, интересы, необязательные контакты и выбор ВУЗа.
- Каталог: 159 активных вузов из Android 0.8.2, программы с кодами и уровнями, поиск, фильтры, контакты, описание, общежитие и военная кафедра, локальные логотипы. Лицензированные программы отмечены отдельно; неизвестные сведения не заменены выдуманными.
- Работа и стажировки: карточки, фильтры, срок вакансии, внешнее оформление отклика на Enbek. Просроченные вакансии скрыты по умолчанию и доступны через фильтр.
- Курсы: направление, формат, город и компания; переход на сайт поставщика. Гранты, IELTS и новости с источниками.
- Наставники: каталог и описание. Для анкет без подтверждённой ссылки запись недоступна.
- Избранное разделено на пять категорий. Новые избранные записи хранятся по стабильным идентификаторам.
- Резюме: редактор, фото, опыт, образование с датами, навыки/языки/интересы, подтверждение закрытия, PDF с чёрной левой колонкой, белым текстом и рамкой фото. Образование слева; должность, зарплата и занятость справа. Длинное резюме разбивается на страницы. Шрифты включены в сборку.
- AI: ручной фокус клавиатуры, чёрные рамки подсказок и ответов, история, повтор после ошибки, диктовка через поддерживаемый браузером SpeechRecognition. Если Telegram WebView не поддерживает его, доступна диктовка клавиатурой.
- Возврат на главную после четырёх минут в фоне. Заставка Flutter 2,5 секунды; лёгкий отклик Telegram HapticFeedback там, где он поддерживается.
- Профиль, выбранный ВУЗ, избранное, резюме и история чата синхронизируются через существующий сервер и PostgreSQL. Несохранённый редактор резюме остаётся черновиком до нажатия «Сохранить». Неотправленные сохранённые изменения переживают повторный вход в тот же аккаунт.

## Как обновить уже созданный Render-сервис

1. Распакуйте Youni4st-miniapp-1.2.0-deploy.zip. Внутри папка **Youni4st-miniapp-telegram-deploy**.
2. В локальном репозитории **wombly/youni4st-server** замените содержимое существующей папки с этим же названием новым содержимым. Не создавайте второй вложенный уровень с тем же названием. Обновите обе папки: **server** и **web_dist**.
3. В GitHub Desktop сделайте Commit и Push origin. Если Render не начал обновление сам, выберите Manual Deploy → Deploy latest commit.
4. Дождитесь успешного запуска. Полностью закройте Mini App в Telegram и откройте заново. Внизу входа и в «О приложении» будет версия **1.2.0**.

Новый бот, новая база и новый сервис не нужны. URL бота остаётся https://youni4st-server.onrender.com. База существующего сервиса не удаляется.

Render:
- Language: Python 3
- Root Directory: `Youni4st-miniapp-telegram-deploy`
- Build Command: `pip install -r server/requirements.txt`
- Start Command: `uvicorn main:app --app-dir server --host 0.0.0.0 --port $PORT --workers 1 --no-access-log`
- Health check: `/health`

Сохраните ранее установленные TELEGRAM_BOT_TOKEN и DATABASE_URL в Render Environment. Они не входят в архив. Для AI на **этом же сервисе** нужны GEMINI_API_KEY, GEMINI_MODEL и CHAT_ENABLED=true. Ключ из существующего AI-сервера можно использовать повторно, но квоты проекта Gemini будут общими. Переменные другого Render-сервиса автоматически сюда не переносятся. Секреты не загружайте в GitHub.

## Исходники и сборка

Editable Flutter source: lib/, assets/, web/, server/, test/.
`flutter pub get`, `flutter test`, `flutter build web --release --no-web-resources-cdn`.
Для Render содержимое build/web копируется в web_dist рядом с server.

## Границы проверки и отличия от Android

Проверки перечислены в docs/VERIFICATION.md. Live-публикация, настоящий Telegram-аккаунт пользователя, PostgreSQL Render и настоящий ответ Gemini из этого окружения не проверялись.
Задержка холодного старта бесплатного Render остаётся свойством хостинга. Код клиента не гарантирует мгновенный первый AI-ответ.
Экспорт/обмен PDF, вибрация, диктовка и обнаружение сворачивания зависят от Telegram WebView и ОС. На iOS браузер может не разрешить диктовку.
Каталог перенесён из релиза 0.8.2, новая интернет-перепроверка всех вузов и вакансий в этом выпуске не выполнялась. Неизвестные контакты/пороги/наличие набора отмечены как неизвестные.
Оплата Kaspi, партнёрский учёт, верификация наставников и новые интеграции работодателей не подключены.
Существующие Android/Firebase аккаунты автоматически не объединяются с Telegram — это разные идентификаторы. Telegram-профили существующей Mini App сохраняются.
