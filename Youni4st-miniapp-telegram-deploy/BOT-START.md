# Приветствие бота /start

Обновление добавляет ответ на /start с именем пользователя и кнопкой «Открыть Youni4st». Обработка только личных сообщений, webhook проверяет секретный заголовок Telegram.

Скопируйте содержимое папки Youni4st-miniapp-telegram-deploy из этого архива в ту же папку, которую Render использует в вашем репозитории. У вас она находится внутри Youni4st-miniapp-1.2.0-deploy. Сохраните текущую структуру папок и Root Directory.
Commit → Push origin → дождитесь успешного Deploy на Render.
При запуске сервер автоматически вызывает setWebhook с ранее сохранённым TELEGRAM_BOT_TOKEN. Дополнительные переменные не нужны. Если у бота ранее был другой webhook, этот обработчик заменит его: он отвечает только на /start, остальные сообщения игнорирует.
После успешного Deploy отправьте новое сообщение /start в @youni4st_bot.

Проверка: 21 Python-тест пройден (2 новых и 19 прежних). Настоящая доставка Telegram будет проверена после публикации пользователем; секретный токен в архив не включён. Веб-интерфейс остаётся версии 1.2.0.
